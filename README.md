# Мемные сайты — Codex skill

Универсальный скилл для создания мемных сайтов: приглашений на вечеринки с RSVP, офисных приколов, поддержки инициатив и голосований разных типов.

Собирает недостающий бриф, сохраняет уже известные ответы и доводит задачу от смысла и работающей механики до мобильной проверки, публикации и QR/постера, если они нужны. Статичный прикол обходится без базы и формы; правила RSVP и голосований выбираются под задачу.

## Установка

В Codex можно попросить `$skill-installer` установить скилл из этого GitHub-репозитория. Для новой ручной установки в пользовательскую папку навыков:

```sh
git clone https://github.com/9federal/meme-sites.git "$HOME/.agents/skills/meme-sites"
```

Также можно скопировать всю папку с `SKILL.md`, включая `agents/`, `references/` и `evals/`, в папку навыков используемого агента. Сохраните их относительную структуру. Если скилл уже установлен, обновляйте его осознанно, сохраняя свои изменения.

В новом чате вызовите `$meme-sites` и опишите ситуацию. Скилл задаст только недостающие релевантные вопросы.

## Примеры запросов

- «Используй $meme-sites: сделай мемное приглашение на вечеринку с RSVP, плюс-один и лимитом мест».
- «Используй $meme-sites: нужен статичный офисный прикол про созвоны, без сбора данных».
- «Используй $meme-sites: сделай голосование с несколькими вариантами и результатами после дедлайна».

Язык сайта, мемы, юмор, данные посетителей, доступ, правила и место публикации определяются брифом.

Пакет содержит инструкции и примеры решений. Исходники готового сайта и подключённые аккаунты в него не входят. Инструменты публикации нужны только для выбранного хостинга; сервер и общая база — для общих голосов/RSVP. В прототипе использовались Framer, Sites/Worker, Cloudflare D1, HTML/CSS/JavaScript, React/TypeScript, Node.js и Python для QR/PDF. Подробности — в разделе об инструментах.

## Как проверять изменения

В отдельном чистом чате/песочнице возьмите запросы из `evals/cases.json`. Проверьте выбор скилла без явного вызова, затем выполнение с `$meme-sites`. Сравните фактический сайт и действия с критериями кейса и `references/quality.md`. Полный запуск проверяет больше, чем чтение инструкции или проверка YAML; визуальное качество также требует просмотра страницы. Тестовые голоса/RSVP остаются в изолированной базе, внешние действия разрешаются отдельно в рамках теста.

Основные рекомендации по формату и проверкам: [Build skills](https://learn.chatgpt.com/docs/build-skills), [Testing Agent Skills with Evals](https://developers.openai.com/blog/eval-skills).
